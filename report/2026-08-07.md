### 2. Tabbed User Profile Dashboard
* Refactored [Profile.jsx](file:///f:/Web_D/Projects/Real_Estate_Website/client/src/pages/Customer/Profile.jsx) into a modern, multi-tab dashboard layout:
  * **URL Syncing:** Synchronizes active selections to the browser query parameters (e.g. `/profile?tab=favourites`) so selected tabs persist on page refreshes.
  * **Tab Categories:**
    1. **Overview:** Highlights welcome prompts, active user statistics (listings and favorites counts), and quick action toggles.
    2. **Favourites:** Displays a grid of property items bookmarked by the user.
    3. **My Listings:** Lists properties published by the logged-in user with built-in Edit and Delete buttons.
    4. **Settings:** Holds the forms to edit avatars, change credentials, update passwords, sign out, or delete profiles.
