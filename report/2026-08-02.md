## 🛠️ Work Done

### 1. Show More Listings Pagination
* **Search Page Logic:**
  * Integrated a `showMore` state boolean inside `client/src/pages/Customer/Search.jsx` to monitor if more listing pages exist.
  * Formulated the `onShowMoreClick` event handler:
    * Automatically calculates the query offset index (`startIndex` parameter matching the current length of rendered listings).
    * Requests the next listing page from the database `/api/listing/get?${query}`.
    * Appends the new listings to the existing state collection (`setListings([...listings, ...data])`).
    * If the returned listing count is less than 9, hides the pagination button by setting `showMore` to false.
  * Added UI validations during the initial load: checks if the initial listings length exceeds 8 items to toggle the visibility of the "Show more" button.
